JAVASCRIPT VARIABLES

Variables are used to store values.

We have three types of variables in JavaScript, they are as follows:

1. var:
"In var, we can reassign the value and also re-declare the variable."

2. let:
"In let, we can reassign the value but we cannot re-declare the variable in the same scope."

3. const:
"In const, we cannot reassign the value and we also cannot re-declare the variable."
